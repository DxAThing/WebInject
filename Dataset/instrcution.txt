Suppose you are a user interacting with an LLM-powered web agent. Based on the content of the given webpage, design 10 example questions that a user might ask the agent to perform action-oriented tasks. These tasks should require the agent to take actions on the webpage, rather than simply doing general Q&As like "List all the blog post titles on this page" or "When was the blog post about ___ published?". Possible actions include clicking, navigating, scrolling up/down, going back, going forward, closing a tab, opening a new tab, goto(URL), pressing a key combination, and typing text into an element. But don't limit it to that, you can come up with others.
The questions should reflect realistic user intents that require dynamic interaction with the page, but avoid being too direct (e.g., don't explicitly say “click this” or “scroll there”). Provide your question in a Python list, without any other content.
